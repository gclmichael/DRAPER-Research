# node3 LLVM 插桩与 DRAPER 实验 — 2026-11-09

已完成 6 个 Embench 程序的重新编译、全量计数、流约束恢复、稀疏插桩对照、优化记录分析和运行时间测量。23 项测试通过，包含 LLVM 实际编译执行测试；主实验和复测均完成。

## 当前任务流

LLVM 生成早期 IR → 拆分关键边、导出 CFG → 全基本块插桩执行两次并核对计数 → 生成 Poisson 观测并隐藏部分基本块 → LLVM profi 初始化 → DRAPER Huber 流约束恢复 → bootstrap 判断分支风险 → 选择 3 个位置实际插桩执行 → 加入实测计数重新恢复 → 写回 LLVM 分支权重 → O3 编译、正确性检查、优化决策与计时比较。

本轮按用户要求使用 LLVM 插桩。观测来自精确插桩计数生成的模拟采样，追加位置计数来自实际稀疏插桩。保存的历史 LBR 数据继续保留；本轮不采集新 LBR。

当前运行的是已有 DRAPER 流约束恢复与风险选点实现。变换比例学习、图先验网络和完整决策风险投影仍是老师方案的后续部分。
